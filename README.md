# أبو هذال - بلوت أونلاين 🃏

مشروع متكامل للعبة البلوت والجاكارو، مستوحى من تجربة "كملنا" ولكن بهوية جديدة وميزات عصرية.

## 🚀 الميزات
- **نظام تسجيل حديث**: تسجيل بالبريد والاسم وباسورد (بدون رقم جوال).
- **لعب جماعي**: دعم اللعب المتعدد عبر Socket.io.
- **تصميم عصري**: واجهة مستخدم سريعة ومتجاوبة مع كافة الشاشات.
- **دردشة فورية**: تواصل مع اللاعبين داخل الطاولة.

## 🛠️ التقنيات المستخدمة
- **Next.js 15** (App Router)
- **Tailwind CSS**
- **Socket.io**
- **Framer Motion**

## 🏁 التشغيل المحلي

1. تثبيت المكتبات:
```bash
npm install
```

2. تشغيل الموقع:
```bash
npm run dev
```

3. تشغيل خادم اللعب:
```bash
npm run server
```

## 🌍 الرفع والتشغيل (Deployment)
المشروع جاهز للرفع على **Vercel** أو أي منصة تدعم Node.js.
تأكد من تحديث رابط الـ Socket في ملف `PlayPage.tsx` عند الرفع على خادم حقيقي.
